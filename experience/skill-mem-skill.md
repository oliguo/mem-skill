**Date:** 2026-02-19
**Skill:** mem-skill
**Context:** Created a self-evolving memory skill for AI agents from two reference repos: Toolsai/auto-skill (5-step core loop pattern) and tobi/qmd (BM25+vector search engine). The skill needed to follow the skill-creator framework conventions exactly.

- Added init.sh with `--mem-engine=qmd` flag for optional QMD setup

## Topic switch threshold: inclusive boundary
**Date:** 2026-02-19
**Skill:** mem-skill
**Context:** Integration test 07-topic-switch revealed that the overlap threshold for topic switch detection used strict `< 0.6` instead of `<= 0.6`. When exactly 40% of keywords change (60% overlap), the switch should trigger per the SKILL.md spec ">=40% keyword change".
**Solution:**
- Changed `overlap < 0.6` to `overlap <= 0.6` in the detection algorithm
- The spec says ">=40% keyword change" which means <=60% overlap (inclusive)
- Borderline test case: ['a','b','c','d','e'] → ['a','b','c','x','y'] = 60% overlap → switch
**Key Files/Paths:**
- examples/07-topic-switch/test.sh
- SKILL.md (Step 2: Topic Switch Detection)
**Keywords:** topic-switch, threshold, overlap, boundary, algorithm, inclusive
